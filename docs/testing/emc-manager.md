# EMC 管理器验收

## 操作方式

- 游戏内按 **F8**，或点击暂停菜单右上角 **EMC 管理器**。按键可在控制设置中更改。
- 搜索物品名称或注册 ID；支持分页和列表区域内滚轮翻页。选择手持物品时只选择它的基础物品类型，不修改其附魔等组件。
- **保存 EMC**：保存正整数自定义值；**删除 EMC**：保存 `0` 以禁用基础物品 EMC；**恢复默认**：删除精确基础物品覆盖。恢复默认不等于保证得到某个固定值，标签覆盖、配方和其他映射器仍会参与计算。
- 完成一批修改后点击 **应用重算**。此操作跳过旧预生成缓存、重算 EMC 并向全服同步，不执行玩家命令、不重载全部数据包。大型整合包可能短暂停顿。
- 变更写入服务端 `config/ProjectE/custom_emc.json`，不是连接玩家的客户端配置。它是该服务器实例的共享配置，不仅影响当前玩家。
- 界面不编辑玩家 EMC 余额，不编辑标签或带数据组件的独立变体。

## 权限

始终检查 `projecte.command` 根权限，然后检查对应节点：

| 操作 | 权限 |
|---|---|
| 保存正值 | `projecte.command.set_emc` |
| 删除 EMC（写入 0） | `projecte.command.remove_emc` |
| 恢复默认（删除覆盖） | `projecte.command.reset_emc` |
| 应用全服变更 | 上述三种权限全部具备 |

未安装权限模组时沿用原指令的 OP 等级 2。界面禁用按钮仅是提示，服务端仍逐条检查请求。应用要求完整权限，因为会应用其他管理员或指令已保存的所有修改。

## 游戏内验收矩阵（需在测试世界执行）

1. **入口与显示**：中文/英文各检查一次 F8、暂停菜单按钮、Tab 导航、搜索名字/完整 ID/命名空间、翻页、无结果、空手按钮禁用；切换 GUI 缩放后输入和选择保留。GUI 可用区小于 300×240 时显示缩放提示。重点确认标题、物品 ID、当前 EMC、自定义值、状态文字和页码均可见：原版 `Screen.render()` 会先绘制背景，自定义面板必须放在 `renderBackground()`，文字放在 `super.render()` 之后，避免背景二次覆盖。
2. **普通玩家**：未授权账号打开界面应收到权限不足；保存/删除/恢复/应用均不可用。开发测试还应直接发 C2S 包验证服务端拒绝，并确认文件没有变化。
3. **细分权限**：只授予 set 权限的账号能设置正值，但不能通过发送 `SET 0` 绕过 remove 权限，也不能应用全服变更。
4. **增改**：选一个没有 EMC 的测试物品，设为 `123`，保存后当前值不立即改变，显示待应用；应用后当前值为 `123`。改成 `456` 再应用，检查 tooltip、转化桌、凝聚器与关联配方。
5. **删除**：确认删除后覆盖为 `0`，应用后基础物品无 EMC。已有标签/组件规则应另外检查，界面不会删除这些规则。
6. **恢复**：重置有覆盖的物品，应用后按原映射重新求值；若原本无 EMC，则仍无 EMC。无覆盖时恢复按钮禁用。
7. **数值**：空输入、0、负号、小数和超过 `9223372036854775807` 的输入不得保存；最大 long 可保存；随后改为有效值不能留下过期错误提示。
8. **持久化**：保存后确认 JSON 正确；关闭界面有未应用提示；重新打开仍能看到覆盖；应用后重启测试服务器，结果应保持。
9. **预生成缓存**：在测试实例启用 `usePregenerated` 后重复增改删/恢复；应用必须忽略旧缓存且更新缓存文件；再次重启结果不回退。
10. **多人同步**：专服上 A 修改并应用，B 已打开的转化桌应刷新；B 的 EMC tooltip 与机器行为一致。内置服务器开启 LAN 后也验证宿主、LAN 玩家和后加入玩家，尤其携带动态注册表组件的物品。
11. **并发冲突**：A、B 同时查询某物品；A 保存新值后 B 用旧状态保存，应拒绝并显示最新值，不覆盖 A 的修改。选择新物品/重开窗口后不接收旧请求的响应。
12. **失败路径**：仅在隔离测试实例中把配置目标设为不可写，保存须报失败且原文件、原内存覆盖不被替换；恢复权限后重试。禁用 CustomEMCMapper 后应用须报明确错误。人工注入映射器异常时不得发送空 EMC 表，原表恢复且仍可重试。
13. **限流**：连续快速编辑提示稍后重试；连续重算间隔不足 5 秒时被服务端拒绝。超时后重新选择物品核实状态，不自动重发写请求。
14. **旧服务端**：客户端安装本版本而服务端无管理器包时，暂停入口不显示，F8 给出不支持提示，不发送未知包。

## Custom conversions

[example_custom_conversion.json](example_custom_conversion.json) is the inherited, commented reference for custom conversion groups and EMC value overrides. It has been moved without changing its contents.

This is a reference example, not a ready-to-install data pack. It includes historical `forge:` tags and a placeholder fluid name. Check the tags, identifiers, and parser behavior supported by the current build before adapting it; do not copy the whole file into a world unchanged. Its comments also mean it is not a strict JSON validation fixture.

Files in this directory are not runtime resources and are not included in the Mod JAR. Current generated game resources remain under `src/datagen/generated`.
